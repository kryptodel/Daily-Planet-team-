Política de Privacidade

Última atualização: Agosto de 2026

1. Introdução

A Daily Planet respeita a privacidade dos usuários. Esta Política explica quais dados coletamos, como usamos e quais são seus direitos em relação aos nossos bots Discord.

2. Dados que Coletamos

Dependendo das funcionalidades do bot, podemos processar:

  • IDs do Discord (usuário, servidor, canais, mensagens) — necessários para o funcionamento dos comandos;
  • Conteúdo de mensagens apenas quando necessário para moderação, logs ou comandos específicos (ex.: filtro de palavrões);
  • Dados de configuração do servidor (prefixos, canais de log, cargos, etc.);
  • Dados de economia/jogos (saldo, inventário, ranking) quando o bot oferece essas funções.

Não coletamos dados sensíveis como senhas, e-mails pessoais ou informações financeiras.

3. Como Usamos os Dados

Os dados são utilizados exclusivamente para:

  • Executar os comandos e funcionalidades dos bots;
  • Manter logs de moderação (quando ativados pelo administrador);
  • Melhorar a estabilidade e desempenho dos serviços;
  • Cumprir obrigações legais, se necessário.

4. Armazenamento e Segurança

Armazenamos apenas o mínimo necessário e pelo tempo necessário para o funcionamento dos bots. Adotamos medidas técnicas razoáveis para proteger os dados contra acesso não autorizado.

5. Compartilhamento de Dados

Não vendemos nem compartilhamos dados pessoais com terceiros para fins comerciais. Podemos compartilhar dados apenas se exigido por lei ou para proteger nossos direitos e segurança.

6. Seus Direitos

Você pode:

  • Solicitar a exclusão dos dados do seu servidor (removendo o bot e entrando em contato conosco);
  • Pedir informações sobre os dados que mantemos relacionados ao seu servidor;
  • Desativar funcionalidades que armazenam dados (quando disponível nas configurações do bot).

7. Cookies e Site

Este site é estático e não utiliza cookies de rastreamento. Não coletamos dados de navegação além do necessário para o funcionamento básico da página.

8. Alterações nesta Política

Podemos atualizar esta Política de Privacidade. A versão mais recente estará sempre disponível nesta página.

9. Contato

Para dúvidas sobre privacidade ou solicitações de dados, fale conosco pelo servidor Discord ou pelo e-mail contato@dailyplanet.bots.
